## ⬜ あなたがやること

### 0. リポジトリを分ける
このフォルダの git の送り先（origin）は、まだ ネミル スマホ の `soshilow/nemiru-iphone` のままです。
GitHub で新しいリポジトリ（例：`soshilow/nemiru-camera`）を作り、送り先を変えてから push してください。
```
git remote set-url origin https://github.com/soshilow/nemiru-camera.git
```

### 1. GitHub Pages を有効にする（プライバシーポリシーURLに必須）
1. GitHub → soshilow/nemiru-camera → Settings → Pages
2. Source：Deploy from a branch ／ Branch：`main`・フォルダ `/docs` → Save
3. 数分後に `https://soshilow.github.io/nemiru-camera/privacy.html` が開けることを確認

### 2. App Store Connect でアプリを作成
https://appstoreconnect.apple.com →「アプリ」→ ＋ → 新規アプリ
- プラットフォーム：iOS ／ 名前：`ネミル カメラ - 中古カメラ・レンズ相場検索`
- プライマリ言語：日本語 ／ バンドルID：`jp.nemiru.camera`（一覧に無ければ先に developer.apple.com → Identifiers で登録）
- SKU：`nemiru-camera-001` など任意 ／ ユーザアクセス：フルアクセス

### 3. 入力する項目（`01_ストア掲載情報.md` からコピペ）
- バージョン情報：プロモーションテキスト／説明文／キーワード／サポートURL／スクリーンショット
- 著作権：`2026 （本名またはデベロッパ登録名）`
- App情報：カテゴリ（ショッピング／写真/ビデオ）、プライバシーポリシーURL
- **コンテンツ配信権**：「サードパーティのコンテンツを含む／表示する」→ はい → 権利を有する（公開ページを開くだけ）
- **年齢制限**：すべて「なし」。「制限のないWebアクセス」は いいえ
- **Appのプライバシー**：「データを収集しない」
- 価格と配信状況：無料 ／ 配信国：日本
- Appレビュー情報：連絡先、サインイン不要にチェック、メモ欄に `04_審査メモ` の英文

### 4. ビルドをアップロード
1. Xcode で `NemiruCamera.xcodeproj` を開き、Signing & Capabilities で Team を選ぶ
2. 上部の実行先を **Any iOS Device (arm64)** に
3. Product → Archive → Organizer → Distribute App → **App Store Connect**
4. 2回目以降はビルド番号（`project.yml` の CURRENT_PROJECT_VERSION）を 2, 3… と上げて `xcodegen generate`

### 5. 審査へ提出
バージョン画面で「ビルド」を選択 →「審査用に追加」→ 提出。
⚠️ ガイドライン 4.3（スパム：似たアプリの量産）で指摘されたら、`04_審査メモ` の「姉妹アプリとの違い」を返信に使う。
