# App Store 申請チェックリスト

## A. 先に決めること（コード修正が必要）
- [x] **バンドルID**を `jp.nemiru.iphone` に変更済み（元のアプリ nemiru とは別アプリ）
- [ ] Apple Developer で App ID `jp.nemiru.iphone` を登録
- [ ] 販売者名（個人名で公開されます。屋号にするには法人登録が必要）
- [x] iPhoneのみで配信（設定済）
- [ ] 他社名（メルカリ等）や「iPhone」「Apple」をアプリ名・アイコンに使っていないことを確認済み（現状OK）

## B. Webページを用意（無料でOK：GitHub Pages / Notion公開など）
- [ ] プライバシーポリシー公開（docs/privacy.html。GitHub の nemiru-iphone リポジトリで Pages を有効にする）
- [ ] サポートURL（連絡先を載せたページ）

## C. 画像
- [x] アプリアイコン 1024×1024（設定済）
- [ ] スクリーンショット（iPhone 6.9インチ：1320×2868 を 3〜10枚）。シミュレータで撮影可
  - ⚠️ screenshots フォルダの画像は元のアプリ（服・靴ページ）のものなので撮り直しが必要
- [ ] アプリアイコンを nemiruスマホ 用にするか検討（今は元のアプリと同じ）

## D. App Store Connect 設定
1. 「マイApp」→ ＋ → 新規App（プラットフォームiOS／名前／言語 日本語／バンドルID／SKU 任意）
2. 01_ストア掲載情報.md の内容を貼り付け
3. Appのプライバシー：「データを収集しません」を選択
4. 年齢制限アンケート、輸出コンプライアンス（暗号化なし：Info.plist 設定済）
5. 価格：無料 ／ 配信国：日本

## E. ビルドのアップロード
1. Xcode → Signing & Capabilities で Team 選択・バンドルID変更
2. 実機 or "Any iOS Device (arm64)" を選び Product → Archive
3. Organizer → Distribute App → App Store Connect → Upload
4. 処理完了後、App Store Connect のバージョン画面でビルドを選択 → 審査へ提出
